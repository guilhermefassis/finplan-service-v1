📊 Entity Model - Financial Planning Application

Complete database structure with relationships

💡 JSONB Fields Explanation

payment_details stores flexible payment information:
• For MONTHLY: {"dayOfMonth": 5}
• For BIWEEKLY: {"firstPaymentDay": 5, "secondPaymentDay": 20}
• Allows queries, indexing, and validation in PostgreSQL

🔗 Entity Relationships

users 1:N credit_cards - A user can have multiple credit cards
credit_cards 1:N credit_card_invoices - A credit card has multiple invoices (one per month)
credit_cards 1:N credit_card_transactions - A credit card has multiple transactions
credit_card_invoices 1:N credit_card_transactions - An invoice groups multiple transactions
users 1:N fixed_expenses - A user has multiple fixed expenses
users 1:N loans - A user can have multiple loans
users 1:N variable_expenses - A user has multiple variable expenses
users 1:N incomes - A user has multiple income records
